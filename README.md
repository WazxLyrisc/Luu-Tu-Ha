# Persona Chatbot (Gemini)

1. Cài Node.js 18+  →  `npm install`
2. Copy `.env.example` thành `.env`, dán GEMINI_API_KEY (lấy ở https://aistudio.google.com/apikey)
3. Sửa `persona.js` cho giống tính cách của bạn
4. `npm start` → mở http://localhost:3000
5. Phản hồi của người dùng được lưu trong `feedback.json`

Thay ảnh đại diện: thay file `public/avatar.svg` (hoặc đổi đường dẫn trong index.html).
